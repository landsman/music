# Frontend

## Stack

- Deno
- Supabase
- Vite
- React
- Vanilla CSS
- [Lucide Icons](https://lucide.dev)
- [react-simple-icons](https://github.com/icons-pack/react-simple-icons)

## Running

You need to have Deno v2.0.0 or later installed to run this repo.

Start a dev server:

```
$ deno task dev
```

## Deploy

Build production assets:

```
$ deno task build
```
